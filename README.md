## ✨ Features

- 💖 **Mathematically Perfect Morphing Heart**: Clickable interactive words (`"I"`, `"love"`, `"you Moonu Toonu"`) that fold into a seamless, tangent-continuous beating heart using precision CSS transforms.
- 👆 **"Hold to Charge" Biometric Scanner**: Futuristic glowing fingerprint pad with an animated vertical laser scan beam and circular SVG progress ring (`0%` ➔ `100%`).
- ⚡ **HTML5 Canvas Electric Plasma Arcs**: Dynamic real-time lightning bolts and sparks crackling between the fingerprint scanner and the heart.
- 💥 **100% Supernova Overload Climax**:
  - **Camera Screen Shake**: Cinematic rumble upon reaching maximum charge.
  - **Blinding Neon Flash**: Radiant pink/white flash explosion.
  - **Particle Burst**: 200+ bursting glowing hearts (`💖`), sparkles, and expanding shockwave blast rings.
  - **Supercharged Heart**: High-frequency throb with chromatic neon aura.
- 🎵 **Synthesized Web Audio Engine**: In-browser frequency-ramped charging drone, plasma crackle, and deep **808 sub-bass heartbeat drop** (100% offline, zero audio file downloads needed).
- 📳 **Mobile Haptics & Responsive Touch**: Vibration feedback (`navigator.vibrate`) on mobile devices and fluid responsive layout on all screen sizes.
- 🎛️ **Live HUD Telemetry Panel**: Real-time readout for `LOVE POWER`, `CORE TEMP (36.5°C ➔ 999°C)`, and `REACTOR STATUS`.
- ⚡ **Re-Charge & Audio Toggle**: Dedicated sound control (🔊 / 🔇) and Re-Charge button to replay the experience endlessly.

## 🚀 Live Demo & Getting Started

### Quick Start
No build steps or dependencies required!

1. Clone or download the repository:
   ```bash
   git clone https://github.com/your-username/heart-animation.git
   ```
2. Navigate to the project directory:
   ```bash
   cd Heart-animation-main
   ```
3. Open `index.html` in any modern web browser (Chrome, Edge, Safari, Firefox).

## 🎮 How It Works

1. **Assemble the Heart**: Click on the words **"I"**, **"love"**, and **"you 'Moonu Toonu' 🥰"**. Watch them smoothly morph into a beating heart.
2. **Charge the Love Reactor**: Press and hold down your thumb/cursor on the glowing **Biometric Fingerprint Scanner**.
3. **Experience the Detonation**: Hold until the energy reaches **100%** to trigger the **Supernova Overload** and unlock the secret love declaration!

## 🛠️ Customization

You can easily personalize this project for your loved one:

- **Change the Recipient Name**:
  Edit the label in [`index.html`](file:///d:/heart%20animation/Heart-animation-main/index.html):
  ```html
  <label for="ck3">you "Your Name" &#129392;</label>
  ```
- **Change the Secret Message**:
  Update the text inside `.overload-banner` in [`index.html`](file:///d:/heart%20animation/Heart-animation-main/index.html):
  ```html
  <p class="banner-message" id="bannerMessage">
    "Your custom romantic love message goes here! 🥰💖"
  </p>
  ```
- **Adjust Charging Speed**:
  In [`script.js`](file:///d:/heart%20animation/Heart-animation-main/script.js), adjust `CHARGE_DURATION`:
  ```javascript
  const CHARGE_DURATION = 2600; // Time in milliseconds (e.g. 2000 for 2 seconds)
  ```
